# **COMMANDS:-**



## &#x20;**> To check origin** 

&#x20;   *Checking: git remote -v*

&#x20;   *Adding:   git remote add origin git@github.com:codingworldx2663-sudo/Git\_Practice.git*

&#x20;   *Removing: git remote remove origin* 



## &#x20;**> To create repository :**

&#x20;   *git init -b <REPOSTORYNAME>*

&#x20;   *git init*




## &#x20;**> To add existing file (or) To make file staged**

&#x20;   *"git add <FILENAME>"*

&#x20;   *"git add ." - For staging all at once.*

&#x20;   *"git restore --staged filename" - To change Staged file into Unstaged file*


## &#x20;**> To commit an existing file**

&#x20;   *git commit -m "MESSAGE"*

&#x20;   *git log - For commit history*



## &#x20;**> To create a key (.pub)**

&#x20;   *ssh-keygen -o - creates .pub file(Key)*



## &#x20;**> To create a tag**

&#x20;   *git tag tagName*

&#x20;   *git show tagName*



## &#x20;**> Branching**

&#x20;   *git branch - Displays all branches*

&#x20;   *git branch branchName - Creates a branch*

&#x20;   *git switch branchName - Switches branch*

&#x20;   *git branch --all - to display all branches in!!* 

&#x20;   *git branch -d BranchName  - To delete existing branch*
